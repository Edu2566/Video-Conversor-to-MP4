# Conversor WMV-MP4

## When I use it?
Util to use with [Free Cam](https://www.freescreenrecording.com) (Fast screen recorder App for computer) to make a fast conversion for your videos.

## How to use?
- Install de dependences using ```pip install requirements.txt```
- Run the code with ```python app.py```
- Browse your Video File
- Click in "Converter"
- Click in "Abrir Video Convertido" to see the result

## When I use?
This app can convert the following types to MP4:

- `.avi`
- `.mov`
- `.mkv`
- `.flv`
- `.webm`
- `.wmv`
- `.mpeg` / `.mpg`
- `.ts`
- `.3gp`
- `.m4v`
- `.ogv`
- `.rmvb`
- `.asf`
- And others...
